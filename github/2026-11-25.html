    32.6 万星的 superpowers 和 20.9 万星的 firecrawl 都只排第 4、5 位，而 2.1 万星的 BugHunter 以 +1,826 位居第一；nginx、OpenVINO 这类老牌基建热度垫底。看趋势要看「今天什么在涨」，而不是页面顺序。

    Ghost-Downloader-3（+1,092）、AutoClip（+980）、minimind（+727）三个中文项目合计 +2,799 星，覆盖下载、剪辑、小模型训练三个方向，说明国内开发者在「实用工具 + AI」赛道仍有很强的势头。

    firecrawl 与 Ghost-Downloader-3 为 AGPL-3.0（商用集成需评估传染性）；app-store-compliance 用的是非标准 OpenRoots ORA-2.3（年营收超 2,000 万美元需付 0.5% 授权费，AI 训练用途另需单独许可）；cursor/plugins 仓库无任何 LICENSE 文件（默认保留所有权利，集成需谨慎）。
