关键判断

5 条
  1. 一个项目吃掉近八成流量，但增速已在回落。

    rea 单日 +41,034，占全榜 79.2%，相当于自身总 star 的 16.6% 一天涨完；较昨日 +54,679 已下降约 25%，趋势算法奖励新面孔而非工程难度，这个数字宜作风向标看待、不宜作标杆。

  2. 剔除爆款后，真实主线是「Agent 基建的第二层」。

    context-mode（上下文压缩）、iFixAi（行为审计）、CLI-Anything（任意软件 Agent 原生化）、K-Dense（177 个科研 Skills）围绕 agent 的 token 成本、可信度、可接入性做配套——agent 经济开始长出中间件层。

  3. 逆向工程被 AI agent 重新点燃。

    rea 把「看功能 → 拆到二进制」做成统一 MCP，直接带火 2019 年诞生、18,739 次提交的 NSA 老牌 Ghidra（今日 +1,008，对成熟期项目极不寻常）；pentagi 是同一逻辑在攻击侧的镜像，SRE/安全的 agent 化值得持续跟踪。

  4. License 雷区密集出现在前三名半。

    VoiceStudio 是 AGPL-3.0（网络服务分发需开源衍生），context-mode 用 Elastic-2.0（source-available，不是 OSI 开源协议，明确禁止托管转售），tiny11builder 没有任何 LICENSE 文件（默认 all-rights-reserved）。选型前务必排雷。

  5. star 与代码量失衡是危险信号。

    iFixAi 约半年攒下 27,612 star，却只有 285 次提交、20 个 release；对比 VoiceStudio 同期 4,145 次提交、42 个 release。前者热度成色要看 issue/PR 的社区跟进速度。
