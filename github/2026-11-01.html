关键判断

6 条
  1. 榜单的头部是惯性，腰部才是新势力。

    前两名 claude-mem（+1,723）与 impeccable（+1,338）都是 10 万星级存量仓库，单日增量只占自身 1.60% 和 1.36%，属于滚雪球；而第 6 名 Orkas 单日增了自身 16.71%、第 3 名 OpenMausBot 增了 13.53%，才是真正从零爆发的项目。判断趋势要看相对增速，不是绝对星数。

  2. 趋势算法奖励新鲜度，不奖励难度。

    用 Zig 从零写 headless 浏览器、累计 11,469 次提交、已做 1,363 天（约 3 年 9 个月）的 lightpanda 只排第 8；而只有 43 次提交、最后一次提交在 13 天前（10-19）的 Claude-Code-Game-Studios 排第 10。superpowers 已 11 天没有提交、devops-exercises 309 天没有提交（上次提交 2025-12-27），仍在榜上。热度与工程强度在本榜单是解耦的。

  3. 「Agent 的记忆与调度」是当前唯一兼具规模与加速的需求。

    claude-mem（跨会话上下文）在不到 430 天内做到 10.8 万星、381 个 release；t3code（多 Agent 控制面）是榜单里唯一明显加速的项目——对照昨日日报，两天累计净增 2,797 星（昨日单日 +930，今日 +1,148），且今日仍在提交。Agent 本身已经够用，卡住生产使用的是状态管理与掌控感。

  4. 昨天的热点今天退了一半。

    昨日在榜的 15 个项目里今天只剩 9 个，6 个跌出榜单（jailbreaks、JetBrains/thinkrail、CopilotKit/OpenBot、anthropics/skills、macro-inc/macro、expo/skills）；其中昨日单日 +2,055、排第 3 的 jailbreaks（无 LICENSE 的越狱提示词集）已彻底消失，提示词/越狱类热度半衰期以天计。impeccable 从 +2,300 回落到 +1,338（降约 42%）、DeepTutor 从 +2,282 回落到 +1,034，第一梯队正从「设计质量」和「AI 教育」向「电脑操作 + 本地多 Agent」切换（OpenMausBot、Orkas 均为今日新上榜）。

  5. 中文赛道出现可复制的「数据工程」样板。

    ziwei-doushu 以 +1,092 排第 5：开源的不是 App，而是排盘算法 + 四化系统 + 格局知识库 + 古籍原文，再加 51.8 万条命盘样本集与 67.5 万命盘 × 13 维（8,774,688 段解读，解压 56.6 GB / 压缩 161 MB，按年份切 77 个文件）的解读数据集，并明确写下「开源边界：什么开源、什么不开源」。软肋是仅 56 次提交、3 个 release——工程极薄、数据极厚，本质是内容项目而非软件项目。

  6. 许可风险需要单列一行，不能只看仓库首页的协议徽章。

    本榜共有 3 个传染性/限制性许可与 2 个多层混合许可：lightpanda 为 AGPL-3.0、vorssaint-utils 为 GPL-3.0（极易被误认成 AGPL，正文里只是引用了 FSF 的交叉条款）；devops-exercises 的 LICENSE 是 CC BY-NC，明文禁止「以商业优势或私人报酬为目的」的使用，且 GitHub 识别结果为 NOASSERTION/Other；ziwei-doushu 分四层——代码 MIT、数据集 CC BY 4.0、古籍公版、倪师原话非商用，而 13 维断语库本体并不开源。直接搬进商业产品需逐层核对，而不是只读 README 徽章。
