关键判断

5 条
  1. Agent Skills 生态今天彻底爆发。

    12 个项目里 9 个直接服务编码 agent：skills 库（Chrome web guidance 单日 +1,219 居首、Google Stitch 设计 skills）、MCP 服务器（chrome-devtools-mcp）、编排器（LoopForge）、交互协议（AG-UI）、评测框架（SkillEvaluator）、红队技能包（BugHunter），「agent 用什么知识、按什么流程干活」本身成了独立赛道。

  2. 榜首是 Google 给 agent 编写的「web 官方教材」。

    modern-web-guidance-src 单日 +1,219、占自身总星数 17%，把 web 平台最佳实践、兼容性数据做成 agent skills，官方下场给编码 agent 纠偏；2026-01-27 创建、1,612 commits，11-14 仍在提交。

  3. 「人在回路」从口号变成产品。

    Plannotator（+866，注解计划/评审 diff/一键回传反馈）、LoopForge（+423，脚本化 SOP + 人工审批门）、阿里 open-code-review（+691，确定性流水线 + LLM 行级评审）都在解决同一痛点：agent 产出多到人看不过来，需要专门的工作台和闸门管理信任。

  4. 斜杠技能包暴露需求缺口。

    claude-trading-skills（+706，占自身总星 12.7%）和 82 个技能、681 个漏洞报告模式的 Claude-BugHunter 证明：通用 agent 外壳已普及，缺口在领域知识包——交易纪律、漏洞模式这些「行业 know-how」被打包成可安装的 skills。

  5. 榜单排序 ≠ 星数排序，算法奖励新东西。

    榜首 7.2k 星的 Chrome 仓库压过 57k 星的 chrome-devtools-mcp；LoopForge 总星仅 1.5k 却单日 +423（占自身总星 28.2%，全榜增速第一）。Trending 明显偏向新锐高增速项目，而非难度大、星数高的老项目。
