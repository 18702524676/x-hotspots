关键判断

5 条
  1. Cloudflare 的「旧仓库新爆发」是今日最大异动。

    security-audit-skill 最后提交停在 2026-09-14（54 天前）、仅 14 次提交、0 个 release，却以 +2,548 登顶（占全榜 27.5%）。爆发源是 6 月 18 日同名博客《Build your own vulnerability harness》的长尾回流——VDH/VVS 架构（128+ 仓库扫描、20,799 候选→7,245 可执行发现、对抗式验证）被社区重新发掘。热度与维护脱节：想要复现 Cloudflare 管线的人拿到的只是「起点」，不是成品。

  2. Skills 赛道进入「官方收编」阶段。

    昨日榜单 1/4 是 skills 仓库，今日仍有 3 个进榜，但构成变了：个人分享型（mattpocock，31.7 万 star）、企业官方型（google/skills，Apache-2.0，昨日仍提交）、安全垂直型（cloudflare）。信号是平台方（Google）和安全大厂（Cloudflare）开始把 skills 当分发渠道，同质化竞争让位于生态位卡位。

  3. NVIDIA/auto-ontology 连续两日稳居前三，增速仍然极端。

    今日 +2,015，占自身总量 22.2%（昨日 +2,679 时为 36.4%），两天累计 +4,694，仓库从 7,352 star 涨到 9,075。「为 agent 构建可信语义层」的叙事在兑现：Apache-2.0、昨日仍有提交、NVIDIA 官方账号运营，商业化路径清晰。

  4. 榜单主体是「可信常青树」，增量贡献却很小。

    zed、vscode、react、rust、rails、angular、symfony、prometheus、etcd、openssl、mpv 等 11 个 2020 年前创建的项目合计 +1,616，仅占 17.5%；单个项目日增最高不过 +306（zed）。这印证趋势算法奖励新奇度——真正的高难度基建（Rust 编译器 34.6 万次提交、vscode 17 万次提交）日增不过 0.0x%。

  5. 许可证视角的提醒。

    zed 主体 GPL-3.0-or-later（gpui 等组件 Apache-2.0），mpv 为 GPL-2.0+，均非宽松许可，企业集成需注意传染性；rust-lang/rust 为 MIT/Apache-2.0 双许可。榜单无「无 LICENSE」仓库，但 cloudflare/security-audit-skill 虽标 MIT，其 README 明确说明这只是 harness 的「单仓库起点」，生产级能力（跨仓库追踪、去重、裁决）在未开源的 VDH/VVS 内部系统里。
