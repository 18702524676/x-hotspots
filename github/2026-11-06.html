关键判断

5 条
  1. 企业级 Agent 上下文层成为最大单点爆发。

    NVIDIA/auto-ontology 单日 +2,679，占自身总量 36.4%，为全榜增量第一。它押注的是「agent 分析可靠性」这一新瓶颈——不是让 agent 更快检索，而是先构建语义本体让 agent 知道数据在哪、含义是什么、能否使用。NVIDIA 背书 + Apache-2.0 + 昨日仍在提交，商业化路径清晰。

  2. 「Skills」赛道已进入平台期内的军备竞赛。

    榜单 1/4 是 skills 仓库：个人分享型（mattpocock，31.5 万 star）、企业官方型（google/skills）、垂直生成型（scenario-labs，做图像/视频/3D）、中文社区型（ConardLi）。技能分发渠道 skills.sh 已现端倪，但同质化严重——除 scenario-labs 绑定自家商业模型管线外，多数仓库缺乏护城河。

  3. Agent 执行层收敛到「无头浏览器 + 无障碍树」路线。

    vercel-labs 的 agent-desktop（操作系统级，+2,173）与 agent-browser（网页级，+150）均用 Rust 写、通过 accessibility tree 而非截图理解界面，配合 worktrunk 这类并行 worktree 工具，「多 agent 并行操作真实桌面」的工具链已成形。

  4. 两个「替代品」故事值得关注。

    floci（+779）以 MIT + docker compose up 正面替代 LocalStack，定位「无账号、无 token、无功能闸门」；DiscImageStudio（+984）则是罕见的纯工具向爆发——光盘盘面图像刻录，GPL-3.0，88 次提交的小仓库单日涨了自身 13.5% 的 star，说明怀旧/硬件玩法仍有流量红利。

  5. 老项目仍在榜但动力衰减。

    lz4（2014 年创建，+23）与 microsoft/VibeVoice（最近提交停在 10-08，已近一个月无更新，+223）上榜更多是存量惯性；语音 AI 赛道迭代极快，VibeVoice 这类热度与维护脱节的项目需警惕。

  • floci-io/floci以「无账号、无 token、无功能闸门」正面替代 LocalStack，观察云服务 API 覆盖广度能否兑现差异化定位。
