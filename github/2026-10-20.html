关键判断

5 条
  1. Trending 奖励新鲜感而非工程难度。

    榜单头部是上线仅 7 个月、395 次提交的 ai-job-search；提交量 2 万+、star 最高的 opencode（217.8k）只排第 3，15 万 star 的 claude-code 垫底（+167，当日增量仅占自身 0.1%）。趋势榜要当「注意力指标」，不是「实力榜」。

  2. 单点爆发：ai-job-search 一天吃掉全场 34% 增量。

    +3,856 相当于自身总 star 的 6.7%；fork 高达 18.2k，fork/star 比 31.8%——「fork 即拥有个人求职流程」被数据验证，但这种爆发通常伴随 HN 式流量脉冲，需警惕增速回落。

  3. 8/12 个项目创建于近 12 个月内，但 momentum ≠ 维护状态。

    Kronos 最后提交停在 2026-04-13（成立一年、仅 76 次提交），CLI-Anything 已近一个月无提交（最后 2026-09-22），靠论文热度/存量口碑仍在涨星；相对增速最健康的是 ai-memory（+5.9%/日）和 jasna（+17.2%/日）。

  4. 许可证红旗要单独盯。

    claude-code 的 LICENSE 是「© Anthropic PBC. All rights reserved」、受商业条款约束——挂在 GitHub ≠ 开源，参考其内部实现有合规风险；jasna 是 AGPL 代码 +「支持者模型」授权码付费，商用前必须确认模型授权边界；os-taxonomy 用数据集专用的 ODbL（含署名-相同共享义务），不是软件许可证。

  5. 发布节奏是质量信号的反向指标。

    ruflo 7 个月发了 1,684 个 release，配合「self-learning、federation、swarm」式宣称，包装/刷屏嫌疑大于实质创新；orca 978 次 release 配 15,243 次提交（约日均 70 次）的高强度真实迭代，两者密度含义完全不同。

值得持续关注

  • akitaonrails/ai-memory跨厂商记忆交接是 agent 生态的「公共基础设施」级缺口，增速最陡（5.9%/日），值得盯 3 个月留存。
  • headroomlabs-ai/headroom榜单最安静的价值股：工具输出/RAG 分块进 LLM 前本地压缩（编码 agent 省 20%、JSON 省 60–95%，示例 10,144→1,260 tokens），成本叙事长期有效，本地处理不吃隐私争议。
  • shiyu-coder/KronosAAAI 2026 接收的 K 线基础模型（45+ 交易所数据），研究价值真实存在；但最后提交已停在 4 月，关注其是否恢复维护再决定是否投入。
