关键判断

5 条
  1. 今日故事线是「给 Agent 发装备」，不是「造 Agent」。

    Agent Skills 生态 7 个项目占今日增量近半（49.9%），形态一致：把某领域专家知识（安全、合规、图表、研究、UI）打包成 Agent 可直接调用的技能库，门槛低、复用强；但内容多为精选文档而非可执行代码，价值依赖维护者持续更新。

  2. Claude-BugHunter 是今天最热也是最具争议的项目。

    创建仅 6 个多月、379 commits，单日 +1,597（占自身总量的 6.5%），榜单第一且远超第二名 53%；85 个技能、681 个已披露漏洞报告模式做成的红队知识库，工程上只是「精心整理的资料」，攻击性定位需自查合规边界，MIT 协议干净。

  3. 趋势算法奖励新鲜感，不奖励难度。

    近 9 千 commit 的 nginx 和 2.4 万 commit 的 OpenVINO 垫底（+150/+176），而 6 个多月的新仓库登顶；文档型技能包普遍压过真正的工程基建，看榜单别把「热度」直接当「分量」。

  4. License 是今天最需要留意的暗坑。

    cursor/plugins 全库无任何 LICENSE 文件（默认保留所有权利），app-store-compliance 用自定义 ORA-2.3 协议，firecrawl 与 Ghost-Downloader-3 为 AGPL-3.0，AFFiNE 后端为企业版私有协议——想商用集成前先读协议。

  5. 中文项目表现强势。

    minimind（从零训练教学）、Ghost-Downloader-3、autoclip 三个国产项目进入今日增量前十，合计 +2,365，占全部增量的 22%。
