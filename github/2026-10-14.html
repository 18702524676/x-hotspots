关键判断

5 条
  1. rea 的数字需要先存疑再看价值。

    6 个月前创建（2026-04-14）就累计 20.9 万 star，今日单仓 +54,679，相当于全天榜单流量的 80.8%、它自身总量的 26.1%。

  2. Agent Skill 已从概念变成货架。

    vercel-labs/skills（npx skills，支持 75+ 代理）是包管理器形态的基础设施，diagram-design、context-mode、rea 则分别把「画图表」「省 token」「逆向」做成了可安装技能。

  3. 协议风险集中出现，不再是小事。

    context-mode 用的是 Elastic License 2.0（源码公开但禁止作为托管服务提供，非 OSI 开源）；VoiceStudio 是 AGPL-3.0（传染性，商用集成需谨慎）；gods-eye-view 代码 MIT 但 README 明确声明捆绑的地理数据与第三方数据源不受 MIT 覆盖。

  4. artcraft 是今日最大的「光环警告」。

    2.58 万 star、4,041 fork，但公开仓库只有 26 次提交、145 个 watcher——发布的多半是宣传引擎而非引擎本身。

  5. xtool 是全场技术含金量最高的项目。

    用 SwiftPM 在 Linux/Windows 上构建、签名、部署 iOS 应用，等于绕开 Xcode 重建 Apple 工具链，直接解放非 Mac 开发者。
