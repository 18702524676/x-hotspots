关键判断

5 条
  1. 榜单几乎是 Agent 生态展。

    13 个项目中 11 个与 AI Agent 直接相关，叙事已从「造 Agent」转向「给 Agent 配装备」——技能库、插件目录、记忆层、编排器；Anthropic 生态占 7 席（claude-code、plugins-official、ECC、ai-job-search、scientific-agent-skills 等均以 Claude Code 为宿主），平台绑定效应显著。

  2. 垂直应用吸星效率首次反超基础设施。

    仅 2 个「AI 具体用途」项目（语音、求职）就贡献了今日 31.6% 的增量，超过 6 个基础设施项目之和（28.9%）；「解决一个疼的问题」的本地化开源工具（VoiceStudio 对标 ElevenLabs、ai-job-search 对标招聘付费服务）正在收割大众开发者情绪。

  3. xerj 是今日最陡的增长曲线。

    创建于 6 月 30 日，7,810 星中单日新增 1,160（占自身总量 14.9%，全榜最高），3,303 次提交、132 个 release，工程投入真实；其「参考编程」主张（同类开源仓库先行索引，agent 输出 token 降 2.7 倍）切中成本痛点，值得作为「AI 检索层」黑马跟踪。

  4. 成熟大厂项目被算法降权。

    claude-code（15.18 万星）与 opencode（21.53 万星）今日仅 +179/+438，分列 12、9 名——再次证明 Trending 奖励新近度而非体量，读榜时须自行按增量与「增量/存量比」双重排序。

  5. 风险信号集中在许可证与供应链。

    claude-code 的 LICENSE.md 实为「© Anthropic. All rights reserved + 商业条款」，源码公开≠开源，商用受 ToS 约束；VoiceStudio 为 AGPL-3.0，闭源集成有传染性合规成本；ECC README 明确警告第三方镜像/重传「可能含恶意代码」——插件目录类项目的供应链安全是 2026 年 Q4 最现实的风险面。
