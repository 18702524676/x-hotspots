  1. Agent 经济重心从模型层下移到「技能 / 上下文 / 运行时」三层基建。

    15 个项目中 12 个与 Agent 直接相关，非 Agent 项目仅 ComfyUI、vllm、Kronos（金融基础模型）。开源创新高地已不在模型本身，而在其上的编排与工具链。

  2. 「上下文工程」正在成为独立赛道。

    graphify（知识图谱化代码库，无向量检索）与 headroom（工具输出压缩，声称省 20–95% token）合计 +1,351 星，二者都不做模型，专做「喂给模型之前的那层」。

  3. 垂直场景 Agent 应用爆发力最强。

    冠军 ai-job-search 单日 +3,861 星，占其自身总量的 6.4%，约为其日均增速（279 星/日）的 13.8 倍——差异化的现实场景（求职）比通用 Agent 框架更容易短期冲榜。

  4. 算法奖励新颖性而非工程量。

    vllm 有 23,472 次提交、今日仅 +128 星排第 13；9.9 万星的 orca 排第 3。判断热度应看「单日新增 / 自身总量」比值，而非页面顺序。
